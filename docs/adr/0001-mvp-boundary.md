# ADR 0001: MVP boundary

Build a narrow Ring-triggered operational case workflow for after-hours delivery-like activity at coworking/shared offices.

Included: Ring ingestion, verification/dedupe, case/context, bounded factual AI brief, allowlisted proposal, explicit human approval, action, audit/evidence.

Excluded from core MVP: autonomous security decisions, door unlocking, generic security dashboard, multi-agent orchestration, broad facility management.
